## 📖 About

This portfolio highlights my journey as a developer — featuring selected projects, core technical skills, and a simple way to get in touch. It's designed with a clean UI, responsive layout, and smooth user experience across all devices.

---

## 🚀 Features

- **Fully responsive** – Optimized for mobile, tablet, and desktop
- **Project showcase** – Each project includes a short description, tech used, live demo, and source code links
- **Skills & experience sections** – Quick overview of my technical toolkit and background
- **Clean, accessible UI** – Minimal design with good readability and accessibility in mind
- **Lightweight & fast** – No heavy frameworks unless needed, loads quickly
- **Easy deployment** – Hosted on GitHub Pages with zero-config CI

## 🧑‍💻 Run Locally

To run this project on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/aman-rai50/amanraiportfolio.git

# 2. Navigate into the project directory
cd amanraiportfolio

# 3. Open with your preferred browser
# Option A: Open index.html directly
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux

# Option B: Use a live server (recommended for development)
# VS Code: Right-click index.html → "Open with Live Server"
# or use npx
npx live-server
